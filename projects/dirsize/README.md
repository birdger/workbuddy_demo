# dirsize 📦

> 终端目录体积分析器 —— [dust](https://github.com/bootandy/dust) 的零依赖 Python 精简版

磁盘又满了却不知道被谁吃掉的？`dirsize` 一条命令把目录里"谁最占地方"用条形图画出来。

## 效果预览

```
📦 G:\code\workbuddy_demo

├── ████████████████████████████  52.3%   41.2M  .git/
├── ██████████                    18.6%   14.7M  projects/
├── ████                           8.1%    6.4M  daily/
├── ██                             4.0%    3.2M  snippets/
└── （其余 3 项）                 17.0%   13.4M
```

## 用法

```bash
python dirsize.py [路径] [-n 条数] [-d 深度] [--files]

python dirsize.py                 # 分析当前目录（只排子目录）
python dirsize.py G:/code -n 15   # 显示最大的 15 个子项
python dirsize.py . -d 2          # 树形递归展示到第 2 层
python dirsize.py . --files       # 文件也参与排序
```

## 参数

| 参数 | 说明 | 默认值 |
|---|---|---|
| `path` | 要分析的目录 | 当前目录 |
| `-n` | 每层显示的最大子项数（超出折叠为"其余 N 项"） | 10 |
| `-d` | 递归展示深度 | 1 |
| `--files` | 让文件也参与排序（默认只排目录） | 关 |

## 原理

1. **体积统计**：`os.scandir` 递归累加每个直接子目录的总字节数；符号链接跳过，权限错误静默忽略。
2. **排序折叠**：每层按大小降序，只保留前 N 项，其余合并成一行，避免刷屏。
3. **可视化**：占比换算成 Unicode 方块 `█` 条形图，配合 `├──/└──` 树形前缀，纯文本也能一眼看出大头。

与 dust 相比：没有多线程和 TUI 配色，但**零依赖、单文件、拷走即用**，Windows 自带 Python 就能跑。

## 运行环境

Python 3.8+，无第三方依赖。
