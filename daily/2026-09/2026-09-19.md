## 💡 每日一技：ES2024 `Object.groupBy`，一行搞定数组分组

以前给数组分组要写 `reduce` 样板代码，ES2024（Node 21+ / 现代浏览器均支持）直接内置了：

```js
const repos = [
  { name: "fzf",   lang: "Go" },
  { name: "bat",   lang: "Rust" },
  { name: "rich",  lang: "Python" },
  { name: "ripgrep", lang: "Rust" },
];

const byLang = Object.groupBy(repos, (r) => r.lang);
// { Go: [fzf], Rust: [bat, ripgrep], Python: [rich] }
```

要点：键必须是字符串/Symbol；想要任意类型作键就用 `Map.groupBy`。完整可运行示例见 [`snippets/2026-09-19/`](../snippets/2026-09-19/)。
