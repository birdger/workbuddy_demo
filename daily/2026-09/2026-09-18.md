## 💡 每日一技：Java try-with-resources，告别手写 finally 关流

Java 7 起把资源声明写在小括号里，无论正常返回还是抛异常，`close()` 都会自动按**逆序**调用，比手写 `finally` 更短、更安全（还能一次管多个资源、自动"抑制"关闭时的二次异常）：

```java
try (FileInputStream in = new FileInputStream(src);
     FileOutputStream out = new FileOutputStream(dst)) {
    byte[] buf = new byte[8192];
    int n;
    while ((n = in.read(buf)) != -1) out.write(buf, 0, n);
} // 不用写 finally，in/out 自动关闭
```

要点：任何实现 `AutoCloseable` 的类（包括自己写的）都能放进小括号。完整可运行示例见 [`snippets/2026-09-18/`](../snippets/2026-09-18/)。
