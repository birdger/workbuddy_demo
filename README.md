## ⚙️ 工作方式

1. WorkBuddy 定时任务每天 09:00 启动
2. 自动检索当日 AI 资讯 → 生成日报 + 小知识 + 趣闻 + 代码 demo
3. `scripts/daily_push.py` 统一提交并推送到四个平台
